# 👋 안녕하세요, 프론트엔드 개발자 이주원입니다.

실제 서비스를 기획부터 개발·배포까지 직접 구현하며 사용자 경험과 서비스 운영을 함께 고민하는 개발자입니다.

---

## 🙋 About Me

실제 서비스를 직접 기획하고 개발하면서 UI 구현뿐만 아니라 데이터 처리, 외부 서비스 연동, SEO, 배포까지 경험했습니다.

프로젝트의 규모와 목적을 고려하여 1인이 개발할 수 있도록 기술과 구조를 선택하고, 단순히 기능을 구현하는 것에서 그치지 않고 실제 사용자가 이용할 수 있는 서비스로 기획해서 완성하는 것을 중요하게 생각합니다. 새로운 기술을 학습하고 프로젝트에 적용하며,  사용자에게 더 나은 경험을 제공할 수 있는 개발자로 지향합니다.

# 🚀 Projects

## 🎨 VIVID ME

### 퍼스널 컬러 & 이미지 브랜딩 서비스

**1인 개발 · 기획 · UI/UX · 기능 개발 · 데이터 처리 · 배포**

퍼스널 컬러 및 이미지 브랜딩 컨설팅을 제공하는 서비스형 웹사이트입니다.

서비스 기획부터 UI 구현, 예약 및 신청 기능 개발, 데이터 처리, SEO 설정, 배포까지 전체 개발 과정을 직접 진행했습니다.

### 🔗 Links

- [Live Demo](https://vivide-me.vercel.app/)
- [GitHub Repository](https://github.com/leeyeonhui050-creator/)

### ✨ 주요 구현

- 모바일 및 PC 환경을 고려한 반응형 UI 구현
- 예약 모달 및 상담 신청 기능 구현
- 체험 신청 폼 구현
- Google Apps Script를 활용한 신청 데이터 처리
- Google Sheets를 활용한 신청 데이터 저장 및 관리
- LocalStorage / Cookie를 활용한 사용자 상태 관리
- robots.txt 및 sitemap.xml 구성
- Google Search Console 등록
- Naver Search Advisor 등록
- Vercel을 활용한 서비스 배포

### 🏗 데이터 처리 구조

별도의 백엔드 서버와 데이터베이스를 운영하는 비용과 복잡도를 줄이기 위해 Google Sheets를 데이터 저장소로 활용했습니다.
Google Apps Script를 중간 계층으로 사용하여 사용자가 입력한 신청 데이터를 Google Sheets로 전달하고 관리할 수 있도록 구현했습니다.
