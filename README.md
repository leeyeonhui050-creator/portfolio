## 🧩 Problem Solving

문제가 발생했을 때 단순히 결과를 수정하는 것보다  
원인을 파악하고 직접 테스트하여 해결하는 것을 중요하게 생각합니다.

```text
Problem
   ↓
원인 분석
   ↓
AI를 활용한 해결 방법 검토
   ↓
직접 구현 및 수정
   ↓
테스트
   ↓
개선
```

프로젝트에서 발생한 주요 문제와 해결 과정은  
각 Repository의 README에 정리하고 있습니다.
