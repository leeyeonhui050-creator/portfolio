실제 서비스를 기획부터 개발, 배포까지 직접 경험한 프론트엔드 개발자입니다.

## 🎨 VIVID ME

> 퍼스널 컬러 & 이미지 브랜딩 서비스

### 📌 프로젝트 소개

2030 세대를 대상으로 퍼스널 컬러 및 이미지 브랜딩 컨설팅을 제공하는 실제 서비스형 웹사이트입니다.

브랜드 소개부터 예약, 체험 신청, 데이터 관리, 검색엔진 최적화까지 실제 서비스 운영을 고려하여 기획하고 개발했습니다.

초기 서비스의 규모와 운영 비용을 고려하여 별도의 서버 및 데이터베이스를 구축하는 대신 Google Apps Script와 Google Sheets를 활용하여 신청 데이터 처리 및 저장 기능을 구현했습니다.


### 주요 구현

- 모바일 / PC 환경을 고려한 반응형 UI 구현
- 예약 모달 및 상담 신청 폼 구현
- Google Apps Script를 활용한 신청 데이터 처리
- Google Sheets를 활용한 신청 데이터 저장 및 관리
- LocalStorage / Cookie를 활용한 사용자 상태 관리
- robots.txt 및 sitemap.xml 구성
- Google Search Console 및 Naver Search Advisor 등록
- Vercel을 통한 서비스 배포


### 기술적 의사결정

초기 서비스 단계에서 별도의 서버 및 데이터베이스를 운영하는 비용과 복잡도를 줄이기 위해 Google Sheets를 데이터 저장소로 활용했습니다.
Google Apps Script를 중간 API 계층으로 사용하여 사용자의 신청 데이터를 Google Sheets에 전달하고 관리할 수 있도록 구현했습니다.
